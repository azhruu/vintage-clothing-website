# 🧥 Maison Archive — Premium Vintage Clothing

> *Rare vintage. Modern attitude. Clothing with memory.*

A fully responsive, production-ready **static ecommerce website** for a premium vintage clothing brand. Built with pure HTML, CSS, and vanilla JavaScript — no frameworks, no dependencies.

---

## 🌐 Live Demo

> Deploy via GitHub Pages:
> `https://azhruu.github.io/vintage-clothing-website`

## 📁 Project Structure

```
vintage-clothing-website/
│
├── index.html              # Homepage — hero, collections, trending, testimonials
├── shop.html               # Shop page — filters, search, sort, product grid
├── product.html            # Product detail — gallery, measurements, condition notes
├── collections.html        # Curated collection edits / lookbook
├── cart.html               # Cart — review items, discount codes
├── checkout.html           # Secure checkout form (demo)
├── order-confirmation.html # Order confirmed page
├── wishlist.html           # Saved / wishlisted pieces
├── search.html             # Search the archive
├── about.html              # Brand story, curation process, values
├── contact.html            # Contact form + FAQ
├── login.html              # Login / Register (split-screen layout)
├── shipping.html           # Shipping & returns policy
├── privacy.html            # Privacy policy
├── terms.html              # Terms & conditions
├── 404.html                # Custom 404 page
│
├── styles.css              # Global styles, layout, components, animations
└── app.js                  # All JavaScript — cart, wishlist, filters, UI logic
```

## ✨ Features

- 🛍️ **Full ecommerce flow** — Browse → Product → Cart → Checkout → Confirmation
- 🔍 **Live search & filters** — Filter by category, size, color, price, condition
- ❤️ **Wishlist** — Save rare pieces locally (localStorage)
- 🛒 **Cart drawer** — Slide-in cart with quantity controls and discount codes
- 👁️ **Quick view** — Preview products without leaving the page
- 📐 **Garment measurements** — Hand-measured sizing for every piece
- 📱 **Fully responsive** — Mobile, tablet, and desktop ready
- ♿ **Accessible** — Semantic HTML, ARIA labels, keyboard navigation
- 🎨 **Editorial design** — Playfair Display + Inter typography
- ✉️ **Newsletter signup** — Archive list subscription form
- 🌙 **Scroll animations** — Reveal-on-scroll for all sections

## 🚀 Getting Started

### View Locally

No build tools required. Just open in your browser:

```bash
# Clone the repo
git clone https://github.com/azhruu/vintage-clothing-website.git

# Open in browser
cd vintage-clothing-website
open index.html   # Mac
# or double-click index.html on Windows
```

### Deploy to GitHub Pages

1. Go to your repository → **Settings** → **Pages**
2. Set source to `main` branch
3. Click **Save**
4. Live at: `https://azhruu.github.io/vintage-clothing-website`
